# Tab Home｜标签主页

[English](README.md) | [简体中文](README.zh-CN.md)

**打开新标签页，管理所有标签与收藏。**

Tab Home（标签主页）是一款 Chrome 扩展插件，用清晰的标签页面板替换浏览器的新标签页。它会按域名整理所有已打开的页面，并将 Gmail、X、LinkedIn 等网站的首页集中到一个分组中。关闭标签页时，还会有音效和彩纸动画。

无需服务器，无需注册账号，也不调用外部 API。安装扩展后即可使用。

## 功能

- **一眼看清所有标签页**：按域名分组，以网格形式展示。
- **首页集中管理**：将 Gmail 收件箱、X、YouTube、LinkedIn、GitHub 等网站的首页放进同一张卡片。
- **关闭动画与音效**：关闭标签页时播放音效，并显示彩纸动画。
- **识别重复页面**：标记重复打开的页面，支持一键清理多余副本。
- **点击即可跳转**：点击标题直接切换到对应标签页，支持跨窗口跳转。
- **稍后再看**：关闭页面前，先点击书签图标，将它保存到待看清单。
- **收藏常用网站**：从 Chrome 书签中选择网站，或手动添加网址，还能拖动调整顺序。
- **窗口与群组**：调整 Chrome 标签栏中的顺序，或在窗口和原生标签页群组之间移动页面。
- **个性化外观**：切换英文或简体中文、自定义配色，每次打开新标签页还可阅读一条双语引言。
- **本地开发端口提示**：在 localhost 标签页旁显示端口号，方便区分不同开发项目。
- **展开更多页面**：每个分组默认显示前 8 个标签页，点击“另有 N 个”（英文界面为“+N more”）可展开其余页面。
- **本地保存**：扩展数据保存在你的设备上。
- **安装即可使用**：无需运行服务器，也无需安装 Node.js 或 npm。

## 手动安装

### 1. 下载仓库

```bash
git clone https://github.com/johnzzyfries/tab-home.git
cd tab-home
```

也可以在 GitHub 仓库页面点击 **Code → Download ZIP**，下载后解压。

### 2. 加载 Chrome 扩展

1. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
2. 打开右上角的 **开发者模式（Developer mode）** 开关。
3. 点击左上角的 **加载已解压的扩展程序（Load unpacked）**。
4. 选择仓库里的 **`extension/` 文件夹**。

安装后，扩展列表中会出现 Tab Home。

### 3. 打开新标签页

打开一个新标签页，即可看到 Tab Home。

## 使用方法

1. 打开新标签页，查看按域名分组的所有标签页。
2. 在顶部的首页分组中，集中查看 Gmail、X 等网站的首页。
3. 点击标签页标题，直接切换到该页面。
4. 点击标签页旁的 **X** 关闭单个页面，或使用分组的全部关闭按钮清理整个分组。
5. 遇到重复页面时，使用清理重复标签页的按钮保留一份。
6. 想留到以后再看的页面，可以先点击书签图标，再关闭它。保存的页面会出现在侧栏。

扩展在 Chrome 内运行，无需外部服务器。稍后再看的页面保存在 `chrome.storage.local` 中，关闭浏览器后仍会保留。

### 窗口与群组

打开 **窗口与群组（Windows & groups）**，查看 Chrome 窗口及其原生标签页群组。

将标签页拖到另一个标签页的上方或下方，即可调整它在 Chrome 标签栏中的位置。也可以拖入某个群组、拖到某个窗口的 **未分组（Ungrouped）** 区域，或通过移动菜单选择目标位置。

显示和操作 Chrome 原生标签页群组需要相应的群组权限。

### 收藏

点击 **编辑收藏（Edit favorites）**，搜索并选择 Chrome 书签，或输入网址添加网站。点击 **保存收藏（Save favorites）** 更新收藏网格。

点击收藏卡片会在新标签页中打开网站；拖动卡片可以调整顺序。已有的自定义收藏会自动加载。

Chrome 书签需要先选择才会显示在收藏中。选中的书签会随 Chrome 书签更新；删除原书签后，对应卡片也会移除。在收藏编辑器中的修改只保存在 Tab Home 本地，不会修改 Chrome 书签。

## 更新扩展

如果通过 Git 下载，在仓库目录中运行：

```bash
git pull
```

如果通过 ZIP 下载，请下载最新版本并解压到原安装位置。

然后打开 `chrome://extensions`，点击 Tab Home 的 **重新加载（Reload）** 按钮，再刷新 Tab Home 页面或打开新标签页。

## 技术实现

- 扩展规范：Chrome Manifest V3。
- 数据存储：`chrome.storage.local`。
- 音效：通过 Web Audio API 合成，无需音频文件。
- 动画：CSS 过渡与 JavaScript 彩纸粒子。

### 开发检查

只有运行测试时才需要 Node.js，正常使用扩展不需要安装它。

```bash
node --test tests/*.test.cjs
```
